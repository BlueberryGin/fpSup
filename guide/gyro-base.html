fpSup-Gyro-Base

While you record, the camera writes the gyro and the accelerometer to one raw .GYR file beside the take — every sample. Afterwards you turn it into a Gyroflow .gcsv in your browser. Version v1.14.0, the same code as fpSup-Gyro v1.14.0. Still being tested.

錄影時,相機把陀螺儀和加速度計寫進片子旁邊的一個原始 .GYR 檔 —— 每個樣本都在。
事後在瀏覽器裡把它轉成 Gyroflow 用的 .gcsv。 版本 v1.14.0,跟 fpSup-Gyro v1.14.0 是同一份程式。仍在測試中。

Install安裝

  1. Check the camera確認相機

    SIGMA fp (not fp L) on firmware Ver.5.02 exactly. How to check.

    SIGMA fp(不是 fp L),韌體必須剛好是 Ver.5.02。怎麼確認。

  2. Build the card in fpSup-Merge在 fpSup-Merge 做卡

    Open fpSup-Merge with fpSup-Gyro-Base ticked. You can add other products to the same card, but not fpSup-Gyro: the two hook the same places, so the page lets you tick only one of them. Then download the zip.

    打開已勾好 fpSup-Gyro-Base 的 fpSup-Merge。 同一張卡可以加其他產品,但不能加 fpSup-Gyro:兩者掛在同樣的位置, 所以頁面只讓你勾其中一個。
    然後下載 zip。

    Fast Start 3 (a faster start after the first boot) is a tick box on the same page. The general guide explains it.

    Fast Start 3(第一次開機之後啟動更快)是同一頁上的勾選框, 通用指南裡有說明。

  3. Copy to the card and start the camera複製到卡上並開機

    Unzip it. Copy AutoRun.txt, fpSup.BIN and the FPSUPUI folder to the root of the SD card the camera boots from. Boot with the USB cable unplugged. The fpSup logo appears top left and four boxes fill one by one. All four white means it is loaded; the camera's own screen comes back two seconds later. If the boxes stop filling, the load stopped there. Details.

    解壓縮。把 AutoRun.txt、fpSup.BIN 和 FPSUPUI 資料夾複製到相機開機用那張 SD 卡的根目錄。
    開機時不要插 USB 線。左上角會出現 fpSup 標誌,四個方格一格一格填滿。 四格全白就是載入完成,兩秒後相機自己的畫面會回來。 方格停在中途,就是載入停在那裡。詳細說明。

  4. Make an empty GYRO folder on every disk you record to在每個錄影用的磁碟上建一個空的 GYRO 資料夾

    In the root of the SD card — and, if you record to one, the root of the USB SSD as well — make an empty folder called exactly GYRO. The log is written beside the clip, on the same disk, and the camera will not create the folder for you.

    在 SD 卡的根目錄 —— 如果你也錄到 USB SSD,SSD 的根目錄也要 —— 建一個名稱剛好是 GYRO 的空資料夾。
    記錄檔寫在片子旁邊、同一個磁碟上,而相機不會幫你建這個資料夾。

    AutoRun.txtboot card only只放開機用的卡
    fpSup.BINboot card only只放開機用的卡
    FPSUPUI\boot card only只放開機用的卡
    GYRO\every disk you record to, empty每個錄影用的磁碟,空的
    Formatting removes the folder. Make it again every time you format a card or the SSD. No folder, no .GYR — and nothing tells you.
    格式化會把這個資料夾刪掉。每次格式化卡或 SSD 之後都要重建。 沒有資料夾就沒有 .GYR —— 而且不會有任何提示。

    Why the camera does not make it: making a folder writes to the file system, and the only two moments it could do that are while a take is starting (which froze the camera) or at boot, when it can only guess which disk you will use.

    為什麼相機不自己建:建資料夾要寫檔案系統,而能做的時機只有兩個 —— 錄影開始的那一刻(試過,相機會凍結),或開機時(那時只能猜你會用哪個磁碟)。

Before you shoot拍攝之前

Base or the gcsv edition?Base 版還是 gcsv 版?

There are two editions of the gyro logger, built from the same code. You can put only one of them on a card.

陀螺記錄器有兩個版本,來自同一份程式。一張卡只能放其中一個。

fpSup-Gyro-BasefpSup-Gyro
camera writes相機寫出 one raw .GYR in \GYRO\一個原始 .GYR,在 \GYRO\ 裡 .gcsv + .json in the clip folder.gcsv + .json,在片子資料夾裡
step after the take拍完之後 convert in the browser在瀏覽器裡轉換 none不用
lens profile .json鏡頭 profile .json not written不寫 written on the camera相機上寫好
GYRO folder needed需要 GYRO 資料夾 yes, on every disk要,每個磁碟都要 no不用

Choose Base if you want the camera to do as little as possible while it records and keep every sample as it was measured. Choose fpSup-Gyro if you want the files ready for Gyroflow the moment you stop, with no folder to make and no file to convert.

想讓相機錄影時做的事越少越好、並保留每個原樣的樣本,就選 Base。
想一停錄就拿到 Gyroflow 可以直接用的檔案、不用建資料夾也不用轉檔,就選 fpSup-Gyro。

This card carries the stream and nothing else: no .gcsv on the camera, no lens profile, no USB shell.

這張卡只帶串流,別的都沒有:相機上不產生 .gcsv、沒有鏡頭 profile、沒有 USB shell。

Use it使用

Record錄影

There is nothing to turn on and no menu to find. Record as usual. Each take writes one file with the take's name into \GYRO\ on the disk the take went to:

沒有東西要開,也沒有選單要找。照平常錄影就好。 每一段會在它錄到的那個磁碟的 \GYRO\ 裡寫一個同名的檔案:

\CINEMA\A001_037\the take片子
\GYRO\A001_037.GYRits motion log它的運動記錄

The file is 64 bytes of header and then nothing but 8-byte records, gyro and accelerometer interleaved in the order they happened. Gyroflow cannot read it directly; convert it first.

檔案是 64 bytes 的檔頭,後面全是 8 bytes 的記錄,陀螺儀和加速度計照發生順序交錯排列。
Gyroflow 不能直接讀它,要先轉換。

Convert the .GYR轉換 .GYR

Open the converter and drop the .GYR on it. It shows the clip, the sample count and rate, the accelerometer and the axis order, then gives you a .gcsv with the clip's name. Everything happens in the page; nothing is uploaded.

打開轉換器,把 .GYR 拖進去。 它會顯示片段、樣本數與取樣率、加速度計和軸向,然後給你一個跟片子同名的 .gcsv。
全部在頁面裡完成,不會上傳任何東西。

The Include the accelerometer box adds the accelerometer columns. Gyroflow uses them to find the direction of gravity.

Include the accelerometer(包含加速度計)這個勾選框會加上加速度計的欄位, Gyroflow 用它來找重力方向。

A file cut off part-way (for example by a power loss during the take) is reported by the converter: records have no framing, so everything after the break is misaligned.

中途被截斷的檔案(例如錄影中斷電),轉換器會告訴你: 記錄之間沒有分隔,所以斷點之後的每一筆都會錯位。

In Gyroflow在 Gyroflow 裡

Load the frames and the .gcsv, then run the sync.

載入影格和 .gcsv,然後執行同步。

You cannot skip the sync, and you cannot reuse a number from last time. CinemaDNG has no timecode, and the log starts about half a second after the first frame — between 470 and 570 ms, and different in every take.

同步不能跳過,也不能沿用上次的數字。 CinemaDNG 沒有時間碼,而記錄的起點比第一個影格晚大約半秒 —— 落在 470 到 570 ms 之間,而且每一次拍攝都不一樣。

Gyroflow asks for a frame rate when you give it a DNG sequence. Enter the rate you recorded at — it cannot read that from the frames.

你把 DNG 序列丟給 Gyroflow 時,它會問你格率。 填你錄影時用的那個 —— 它沒辦法從影格裡讀出來。

The lens profile鏡頭 profile

Base writes no .json. Use Gyroflow's own lens calibration: you film a calibration target, Gyroflow works out the real distortion of your lens and saves a profile you can reuse for that lens. This works the same with adapters and manual lenses.

Base 版不寫 .json。請用 Gyroflow 自己的鏡頭校正: 拍一張校正圖卡,Gyroflow 會算出你鏡頭真正的畸變,存成一個 profile,以後那顆鏡頭都能重複用。
轉接環和手動鏡頭也一樣適用。

The older converter can also make a .json from a lens name and focal length you type in. The camera does not record which lens was on it, so that profile leaves distortion at zero.

舊版轉換器也能依你輸入的鏡頭名稱和焦距產生 .json。相機不會記錄當時掛的是哪顆鏡頭,所以那個 profile 的畸變是零。

If you work in DaVinci Resolve如果你用 DaVinci Resolve

There is a Gyroflow plugin for Resolve, so you can stabilise on the timeline instead of exporting from Gyroflow first. It reads the converted .gcsv.

Resolve 有 Gyroflow 的外掛,可以直接在時間軸上穩定, 不用先從 Gyroflow 匯出。它讀得懂轉出來的 .gcsv。

Portrait takes need nothing special — the camera records every frame landscape upright, so Gyroflow reads them like any other take. Leave horizon lock off.

直拍的素材不用做任何特別處理 —— 相機每一格都是以橫向正立記錄的,所以 Gyroflow 讀它跟讀其他素材一樣。 水平鎖定維持關閉就好。

Remove移除

fpSup-Gyro-Base adds no menu item, so there is no setting to put back first. Delete AutoRun.txt, fpSup.BIN and FPSUPUI, or take the card out, then switch the camera off. The card writes back every firmware word it changed as the camera powers off. If the camera froze instead, take the battery out (USB cable unplugged). General removal.

fpSup-Gyro-Base 沒有加任何選單項目,所以沒有設定要先改回去。
刪掉 AutoRun.txt、fpSup.BIN 和 FPSUPUI,或把卡拿出來,然後關機。 相機關機時,卡片會把改過的每個韌體字寫回去。 如果相機是凍結了,就把電池拿出來(不要插 USB 線)。通用的移除說明。

The GYRO folders and the .GYR files are ordinary files; keep or delete them as you like.

GYRO 資料夾和 .GYR 檔都是一般檔案,留著或刪掉都可以。
