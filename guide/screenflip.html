fpSup-ScreenFlip

Turns the rear screen 180°, mirrors the picture, or both. Each custom display mode keeps its own choice, and the screen changes when you switch into that mode. Version v0.1.0test — a test build.

把背螢幕翻轉 180°、把影像鏡像,或兩者都做。每個自訂顯示模式各記一個選擇, 切換進那個模式時螢幕才改變。版本 v0.1.0test —— 這是測試版。

Install安裝

Tick fpSup-ScreenFlip in fpSup-Merge, download, and put it on the card as the install steps on that page say.

在 fpSup-Merge 勾選 fpSup-ScreenFlip 下載,照頁上的安裝說明放進卡。

The four choices四個選項

When it flips什麼時候翻

Setting a value does not flip the screen. It flips when the camera enters that display mode.

設定值不會讓螢幕翻轉。相機切換進那個顯示模式時才翻。

Eight choices, kept on the card八個選擇,存在卡上

  • The choices are saved into fpSup\40FLIP.BIN itself, about a second after you stop changing them, and never while recording. Nothing goes into the camera's own settings. 選擇存進 fpSup\40FLIP.BIN 檔案本身:停止更改約一秒後才存,錄影中不存。 相機自己的設定裡不寫任何東西。
  • The row shows the choice of the custom mode you opened. 選單列顯示的是你打開的那個自訂模式的選擇。

Limits限制

  • Changed the custom mode you are in? Switch away and back once to see it. 改的是目前所在的自訂模式?切走再切回來一次才看得到。
  • Plugging or unplugging HDMI puts the screen back to normal. Switch display mode once to flip it again.插拔 HDMI 會讓螢幕恢復正常。再切一次顯示模式就會翻回來。
  • Only the rear screen. On the EVF it has no visible effect. 只作用在背螢幕。使用 EVF 時看不出效果。
  • Other products on the same card that add menu text must come from the same generation of fpSup-Merge (2026-10-07 or later); an older one is skipped at start. 同一張卡上會加選單文字的其他產品,必須是同一代 fpSup-Merge(2026-10-07 以後)做的; 較舊的會在開機時被略過。

What is tested and what is not測過什麼、沒測過什麼

This is a test build. It has not been run on the camera as released.
這是測試版。發布版本身還沒在相機上跑過。
tested on the camera已在相機上測過not tested沒測過
Development builds of the same design (2026-10-06/07): the row works; 180 and 180+Mirror flip when entering the mode and not when set.同設計的開發版(2026-10-06/07): 選單列可用;180 與 180+Mirror 在切入模式時翻、設定時不翻。 This release’s own files.本發布版的檔案本身。
On one card with Lossless, Gyro, Open Gate 3K and RAW view: all loaded. 與 Lossless、陀螺儀、Open Gate 3K、RAW view 同卡:全部載入。 Saving across a restart: the development builds never saved; fixed in this release, not yet seen on the camera.重開後保留:開發版從沒存成功; 本版已修,還沒在相機上看過。
Mirror alone (picture only).單獨 Mirror(只翻影像)。

Remove移除

Delete fpSup\40FLIP.BIN and restart the camera; nothing was written to the camera’s settings.

刪掉 fpSup\40FLIP.BIN 後重開相機即可;相機設定裡沒有寫任何東西。

If something does not work如果有東西不能用

what happens發生什麼what to do怎麼辦
No Screen Flip row on TOOLSTOOLS 頁沒有 Screen Flip 列 The card did not load, or another product on it is from an older generation. See general problems.卡沒有載入, 或卡上有較舊一代的產品。見一般問題。

Flip gone after plugging HDMI插 HDMI 後翻轉不見了 Switch display mode once.切一次顯示模式。
