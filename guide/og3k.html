fpSup-OG3K

Records the sensor's whole 3:2 area as CinemaDNG — 3024×2010, 8, 10 or 12-bit, 23.976 to 100 fps — instead of the 16:9 window the camera normally uses. Version v0.2.6a. This is an alpha: treat every take as disposable until you have checked it.

把感光元件整個 3:2 範圍錄成 CinemaDNG —— 3024×2010、8/10/12-bit、23.976 到 100 fps —— 而不是相機平常用的 16:9 範圍。版本 v0.2.6a。
這是 alpha 版:每段錄影在你檢查過之前,都當成可能不能用。

Install安裝

  1. Check the camera確認相機

    SIGMA fp (not fp L) on firmware Ver.5.02 exactly. How to check.

    SIGMA fp(不是 fp L),韌體必須剛好是 Ver.5.02。怎麼確認。

  2. Build the card in fpSup-Merge在 fpSup-Merge 做卡

    Open fpSup-Merge with fpSup-OG3K ticked. You can add the gyro logger to the same card. You cannot add OG2K: both need the camera's third resolution slot, so the page will not let you tick both. Download the zip.

    打開已勾好 fpSup-OG3K 的 fpSup-Merge。
    同一張卡可以再加陀螺儀記錄。不能加 OG2K:兩個都要用相機的第三個解析度欄位, 所以頁面不會讓你兩個都勾。下載 zip。

  3. Copy to the card and start the camera複製到卡上並開機

    Unzip. Copy AutoRun.txt, fpSup.BIN and the FPSUPUI folder to the top level of the SD card the camera starts from. Put the card in and turn the camera on with the USB cable unplugged. Details.

    解壓縮。把 AutoRun.txt、fpSup.BIN 和 FPSUPUI 資料夾複製到相機開機用的那張 SD 卡的最上層。
    插卡,拔掉 USB 線再開機。細節。

    The fpSup logo appears in the top left and four boxes fill one by one. All four white means it loaded; the camera's own screen comes back two seconds later. If the boxes stop filling, the load stopped there — see below.

    左上角會出現 fpSup 標誌,四個方格一格一格填滿。 四格都變白就是載入完成,兩秒後相機自己的畫面會回來。
    方格停住不再填,就是載入停在那裡 —— 看下面。

Before you shoot: storage speed拍之前:儲存速度

OG3K writes a lot of data. One 12-bit frame is 9.2 MB, and CinemaDNG writes one file per frame.

OG3K 的資料量很大。一格 12-bit 是 9.2 MB,而 CinemaDNG 是一格一個檔。

what you record你錄什麼per frame每格speed needed需要的速度
OG3K, 24p, 12-bitOG3K,24p,12-bit9.20 MB221 MB/s
OG3K, 24p, 10-bitOG3K,24p,10-bit7.68 MB184 MB/s
OG3K, 24p, 8-bitOG3K,24p,8-bit6.16 MB148 MB/s
the UHS-II SD card we measured我們量過的 UHS-II SD 卡94 MB/s
an external SSD we measured我們量過的外接 SSD390 MB/s

If the storage is too slow, the camera stops recording after a few seconds. No setting fixes that. We recorded 31 OG3K clips to that 94 MB/s card and every one stopped at 4.1 seconds or less. With 9.2 MB files the card only reached 66 MB/s, so the real gap is close to 3×.

儲存太慢的話,相機會在幾秒後停止錄影,沒有任何設定救得了。
我們在那張 94 MB/s 的卡上錄了 31 段 OG3K,每一段都停在 4.1 秒以內。 用 9.2 MB 的檔案,那張卡只跑到 66 MB/s,所以真實差距接近 3 倍。

For OG3K, record to an external SSD over USB-C. It is the only storage we have measured that is fast enough. We have measured only one SD card, so we cannot say no SD card can do it — run the storage benchmark on the camera first; the number printed on the card is not the number you get.

OG3K 請錄到 USB-C 外接 SSD。它是我們量過唯一夠快的儲存。
我們只量過一張 SD 卡,所以不能說「沒有 SD 卡做得到」—— 先在相機上跑儲存 benchmark; 卡上印的數字不是你拿到的數字。

Want to stay on SD? Use OG2K instead. Same full 3:2 picture at 98 MB/s — if your card records normal FHD cleanly, it records OG2K.

想繼續用 SD 卡?改用 OG2K。 同樣的完整 3:2 畫面,只要 98 MB/s —— 你的卡能乾淨錄一般 FHD,就能錄 OG2K。

Use使用

1. Turn Super35 / crop off. With crop on, OG3K cannot record: you press record, nothing happens, and the camera does not say why.

1. 把 Super35 / crop 關掉。裁切開著的時候 OG3K 錄不了: 按下錄影什麼都沒發生,相機也不會告訴你為什麼。

2. Set the recording format to CinemaDNG. OG3K only exists while the format is CinemaDNG. Switching to MOV withdraws it; switching back brings it back.

2. 錄影格式設成 CinemaDNG。OG3K 只在 CinemaDNG 格式下存在。 切到 MOV 它就退出,切回來它就回來。

3. Choose OG3K in MENU → recording → resolution or Quick Set → RES. Choose the frame rate and CinemaDNG quality (8, 10 or 12-bit) as you normally would.

3. 選 OG3K:MENU → recording → resolution 或 Quick Set → RES。
格率和 CinemaDNG 品質(8/10/12-bit)照平常的方式選。

The camera remembers the choice. If OG3K was the last resolution and the format is CinemaDNG, the card selects it again after the next start. That is why removal has an order.

相機會記住這個選擇。如果最後選的是 OG3K、格式是 CinemaDNG, 下次開機卡片會自動再選回它。這就是為什麼移除有順序。

What is tested and what is not測過什麼、沒測過什麼

Tested on a SIGMA fp, Ver.5.02:

在 SIGMA fp、Ver.5.02 上測過:

  • 12-bit recording, 3024×2010 with the 3008×2000 crop, sharp edge to edge; 12-bit in-camera playback.12-bit 錄影,3024×2010 帶 3008×2000 裁切,邊到邊清晰;12-bit 機內播放。
  • 10-bit and 8-bit recording at the right size per frame, with no fallback to UHD and no colour shift in the preview.10-bit 與 8-bit 錄影,每格大小正確,不會退回 UHD,預覽沒有偏色。
  • All 5 frame rates × 3 bit depths tested on 2026-09-22 recorded correctly.2026-09-22 測的 5 種格率 × 3 種位元深度都錄得正確。
  • 25p at 1/50 s (180°): all 100 DNG frames checked, OG3K next to UHD and FHD.25p、1/50 秒(180°):OG3K 與 UHD、FHD 共 100 格 DNG 全部檢查過。
  • MOV + REC with OG3K selected no longer freezes the camera; OG3K is restored after a restart.選著 OG3K 時切 MOV 按錄影不再凍結;重開機後 OG3K 會被選回來。
  • Live view in standby, half-press and recording; the Quick Set and CINE settings screens.待機、半按、錄影中的即時預覽;Quick Set 與 CINE 設定畫面。

Not tested, or expected to be broken:

沒測過,或預期有問題:

  • In-camera playback of 8-bit and 10-bit clips — expect it to be broken.8-bit 與 10-bit 片段的機內播放 —— 預期是壞的。
  • Highlight headroom at 8-bit and 10-bit (12-bit is verified).8-bit 與 10-bit 的高光餘裕(12-bit 已驗證)。
  • A still photo taken while OG3K is selected.選著 OG3K 時拍靜態照片。
  • Switching CINE/STILL while OG3K stays selected.OG3K 保持選取時切換 CINE/STILL。
  • Exact shutter readback at frame rates other than 25p.25p 以外格率的精確快門讀回。
  • Long takes on fast enough storage.在夠快的儲存上長時間錄影。
  • This exact card: its newest changes (restore from the loader, the power-off write-back, the Quick Set fixes) were measured on OG2K, which carries the same routines, not on OG3K.這一張卡本身:最新的改動(從 loader 還原、關機寫回、Quick Set 修正)是在帶同樣程式的 OG2K 上量的,不是在 OG3K 上。

One early OG3K test with a debug build froze after creating a clip. Later attempts did not repeat it. The full list is in the release README.

早期一次用 debug 版測 OG3K,在建立片段後凍結過,之後沒再重現。 完整清單在發行版 README。

Remove — set the resolution back first移除 — 先把解析度設回去

The order matters. The camera remembers the resolution on its own, and deleting the files does not clear it. If you delete the files while the camera is still on OG3K, it is set to something that no longer exists and will not record properly.
順序很重要。相機會自己記住解析度,刪檔案不會清掉它。
如果相機還停在 OG3K 就把檔案刪了,它就停在一個已經不存在的東西上, 錄不出正常的東西。

1. While the card still works: set the resolution back to UHD or FHD in MENU → recording → resolution or Quick Set → RES.

1. 趁卡片還能運作時:在 MENU → recording → resolution 或 Quick Set → RES 把解析度設回 UHD 或 FHD。

2. Then delete the files from the card, or take the card out, and switch the camera off. Details.

2. 然後把卡上的檔案刪掉,或把卡拿出來,再關機。 細節。

Already did it in the wrong order? Nothing is broken. Put the card back with its files, start the camera so OG3K exists again, set UHD or FHD, then remove it again.

已經照錯的順序做了?沒有東西壞掉。 把帶著檔案的卡插回去、開機讓 OG3K 重新存在、設成 UHD 或 FHD,再移除一次。
